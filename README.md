# Java Study

My personal Java learning repository.

The goal is not to create production-quality code here.

The goal is to understand Java by:

1. Learning a concept
2. Writing a small example
3. Breaking it
4. Experimenting
5. Documenting what I discovered
6. Connecting it with previous concepts
